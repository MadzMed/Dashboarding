# Exercice Power BI — Refonte du dashboard Peaks Cycles

## Contexte

Vous récupérez un rapport Power BI **Peaks Cycles** déjà construit, mais mal organisé.

Votre objectif est de le transformer en un **dashboard clair, professionnel et orienté décision**.

## Travail demandé

### 1. Réorganiser le dashboard

- Aligner et redimensionner les visuels.
- Supprimer les éléments inutiles ou redondants.
- Mettre en avant les informations les plus importantes.
- Créer une hiérarchie visuelle claire.

### 2. Ajouter des KPI

Ajoutez entre **4 et 6 KPI maximum** sur la page principale.

Exemples selon les données disponibles :

- Chiffre d’affaires
- Nombre de ventes
- Quantité vendue
- Nombre de clients
- Panier moyen
- Évolution par rapport à la période précédente

Les KPI doivent permettre de comprendre rapidement la situation globale.

### 3. Séparer les analyses sur plusieurs pages

Créez au minimum **3 pages** :

#### Page 1 — Overview
- KPI principaux
- Évolution générale
- Informations importantes à retenir

#### Page 2 — Analyse des ventes
- Évolution des ventes
- Comparaison entre produits ou catégories
- Meilleures et moins bonnes performances

#### Page 3 — Analyse complémentaire
Au choix :
- Analyse géographique
- Analyse clients
- Analyse produits
- Autre analyse pertinente

### 4. Améliorer les couleurs

Les couleurs doivent servir à transmettre une information.

Par exemple :

- couleur principale pour les données normales ;
- couleur positive pour une bonne performance ;
- couleur d’alerte pour une mauvaise performance ;
- couleur d’accent pour attirer l’attention.

Évitez d’utiliser une couleur différente pour chaque graphique.

### 5. Améliorer les titres

Évitez les titres trop génériques comme :

- `Sales`
- `Sales by Month`
- `Revenue by Category`

Préférez des titres qui facilitent la compréhension du graphique.

### 6. Ajouter des filtres utiles

Ajoutez uniquement les filtres nécessaires, par exemple :

- période ;
- catégorie ;
- région ;
- produit.

Évitez de surcharger le dashboard avec trop de slicers.

## Contraintes

Votre dashboard doit respecter les règles suivantes :

- minimum **3 pages** ;
- maximum **6 KPI par page** ;
- palette de couleurs cohérente ;
- alignement propre des éléments ;
- utilisation de l’espace blanc ;
- pas de visuels purement décoratifs ;
- navigation claire entre les pages ;
- au moins une évolution temporelle ;
- au moins une comparaison entre plusieurs catégories.
